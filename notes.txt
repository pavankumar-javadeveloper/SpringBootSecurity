filters:
-------
AuthorizationFilter
DefaultLoginPageGeneratingFilter
AbstractAuthenticationProcessingFilter

above filters will be useful for to display the login page.

after login spring boot security page

open network tab there you can see cookies option.
there we can find the endpoint.
once we click on the endpoint we can see the JSESSIONID cookie.
once login is success spring boot won't ask login page.
if we change the JSESSIONID value it will get redirect to login page again.
that means once authentication success if the JSESSIONID is same it won't show login page again.
